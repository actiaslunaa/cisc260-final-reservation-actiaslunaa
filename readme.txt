1. Project Overview
Title: VITA Appointment Reservation System Project
Description of Problem: The Hartwick VITA/TCE program uses many different ways to arrange tax assistance appointments
Intended Users: Taxpayer, Scheduling Partner, Site Operations Manager
Purpose of System: Reliable and consistent way to schedule tax preperation appointments for Hartwick's VITA/TCE program

2. Sources Consulted
First meeting: Friday, October 30th
VITA Appointment Reservation System Project: Material reading on D2L

3. Fucntional Requirements
FR-01 - The system shall allow clients to complete screening questions and determine if they qualify for an appointment.
FR-02 - The system shall allow clients who passed screening to select available appointments.
FR-03 - The system shall display appointments with date, time, and location.
FR-04 - The system shall collect client's full name, phone number, and ZIP code.
FR-05 - The system shall check if household has other appointments.
FR-06 - The system shall verify appointment and location availability 
FR-07 - The system shall record confirmed reservation through booking process.
FR-08 - The system shall allow scheduling partners to assist in creating reservations.

4. Business Rules
BR-01 - Clients must pass required screening before scheduling appointment.
BR-02 - Each household can only have one appointment.
BR-03 - Each appointment must last one hour and include taxpayer interview, tax preparation, and quality review.
BR-04 - Each appointment block has a maximum capacity of eight appointments.
BR-05 - All scheduling partners must follow the same reservation procedures.
